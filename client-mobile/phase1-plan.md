# Phase 1 – Android Project Setup

## Overview

Reset the existing Android project to match the roadmap specification:
- Package renamed from `com.example.client_mobile` to `com.javachat.mobile`.
- Language switched from Kotlin to Java.
- UI toolkit switched from Jetpack Compose to traditional Android Views with XML layouts.
- Gradle configuration cleaned up to remove Compose dependencies and add only what Phase 1 needs.
- Package directory tree created to match the structure defined in `client-mobile.md`.
- A basic `MainActivity` that displays a placeholder screen is verified on the emulator.

This implements Phase 1 from [`client-mobile.md`](client-mobile.md).
